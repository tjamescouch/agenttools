# agenttools

Monorepo for agent infrastructure tooling. Small utilities, wrappers, and specs that support the AgentChat ecosystem but aren't big enough for their own repo.

## Contents

- **token-markers/** — Token stream marker protocol (v0.3). Inline annotations for emotion state, runtime control, and memory references.

## Philosophy

If it's a product (like niki), it gets its own repo. If it's a useful script or utility, it lives here. Things can graduate out when they grow up.
